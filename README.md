# 荒唐無稽仮説発射台

ブラウザで動く静的なアイデア発散ツールです。

## 使い方

`index.html` をブラウザで開くと起動します。

- テーマを入力して「次へ」
- 2軸マトリクスで仮説を生成
- 横軸と縦軸はそれぞれ独立して変更できます
- リスト画面で「深める」を押して、荒唐無稽な問いを追加
- 起動するたびに前回までの入力と保存アイデアは消えます

記事の思想と画面の空気感を参考にしつつ、ロゴや画像などのサイト固有資産は使っていません。

## GitHub Pages

このリポジトリは `.github/workflows/pages.yml` により、`main` ブランチへ push すると GitHub Pages へ公開されます。
